# Chat app Implementation Plan

Working document, not committed.

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** A personal chat app — one sidebar with New chat, the user's recent chats across their workspaces and the management pages — and a harness picker for new chats.

**Architecture:** Two read endpoints at user level derive conversations from `runs`; every write stays on the workspace endpoints. One `Shell` with one `AppSidebar` wraps every signed-in page in `_authed.tsx`; the chat body is lifted out of the run page into `/c/$conversationId`, and the run page becomes a redirect.

**Tech Stack:** Go, gin, oapi-codegen, sqlc/pgx, goose, testify; React 19, TanStack Router/Query, Tailwind/shadcn, Vitest + MSW, Playwright; new `react-icons`.

**Spec:** `docs/superpowers/specs/2026-10-08-chat-app-design.md`

## Global Constraints

- Spec first (`schema/openapi.yaml`), then `task generate`; never edit generated code; commit it.
- Tests first; testify; never discard an error; `task lint`, Biome and `tsc` clean.
- Title: first run's input, first **100** characters, cut in SQL with `left()`.
- Paging: `limit` 1–200, default 50 (`api.DefaultRunsLimit`, `api.MaxRunsLimit`); cursor `"<latest activity, Unix µs>.<conversation ID>"`; malformed → 400. Run IDs are `rand.Text()` (base32, no `.`).
- Only the caller's own conversations, only workspaces they are a member of now.
- Icons `react-icons/lu`, `aria-hidden`; every control has a visible label or `aria-label`. Tests query by role and label.
- `git add` explicit paths only. Do not commit `docs/superpowers`.

## Review Focus

1. A user's conversation in a workspace they left (alice in `work`) → not listed, not found (Task 2).
2. A follow-up on the cursor's conversation between pages → the next page neither repeats nor skips (Task 1).
3. A member follows up another user's conversation → it stays the starter's (Task 1).
4. `/c/<unknown or foreign id>` → "Conversation not found" (Task 5).
5. No workspaces / no harnesses → New chat explains and links to management, no dead select (Task 6).

```sql
-- name: ListConversations :many
-- The conversations started_by started in the given workspaces, latest
-- activity first, after the one at before_at and before_id when set. A
-- conversation is its first run, whose ID names it, and its latest run, the
-- one no run follows.
SELECT first.id, harness_versions.workspace, harness_versions.name AS harness,
       left(first.input, 100)::text AS title, latest.created_at AS updated_at
FROM runs first
JOIN harness_versions ON harness_versions.id = first.harness_version_id
JOIN runs latest ON latest.conversation_id = first.id
 AND NOT EXISTS (SELECT 1 FROM runs n WHERE n.follows = latest.id)
WHERE first.id = first.conversation_id
  AND first.started_by = sqlc.arg(started_by)
  AND harness_versions.workspace = ANY(sqlc.arg(workspaces)::text[])
  AND (sqlc.narg(before_id)::text IS NULL
       OR (latest.created_at, first.id) < (sqlc.narg(before_at)::timestamptz, sqlc.narg(before_id)::text))
ORDER BY latest.created_at DESC, first.id DESC
LIMIT sqlc.arg(max_rows);

-- name: FindConversation :one
-- The conversation named by id, if it is in one of the given workspaces.
SELECT first.id, harness_versions.workspace, harness_versions.name AS harness,
       left(first.input, 100)::text AS title, first.created_at AS updated_at
FROM runs first
JOIN harness_versions ON harness_versions.id = first.harness_version_id
WHERE first.id = sqlc.arg(id) AND first.id = first.conversation_id
  AND harness_versions.workspace = ANY(sqlc.arg(workspaces)::text[]);
```

`FindConversation`'s `updated_at` is unused by callers; select only what the API needs if sqlc's row type then differs — map explicitly either way.

```go
// conversationCursor names the conversation a page of them ends with: its
// latest activity, in microseconds as stored, and its ID.
func conversationCursor(cv store.ConversationSummary) string {
	return strconv.FormatInt(cv.UpdatedAt.UnixMicro(), 10) + "." + cv.ID
}

func parseConversationCursor(s string) (time.Time, string, error) {
	micros, id, ok := strings.Cut(s, ".")
	at, err := strconv.ParseInt(micros, 10, 64)
	if !ok || err != nil || id == "" {
		return time.Time{}, "", fmt.Errorf("before %q: not a cursor this API gave", s)
	}
	return time.UnixMicro(at), id, nil
}
```
